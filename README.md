# Hundi

Onchain invoice financing on Whitechain. An exporter sells an unpaid invoice to verified investors for USDT today, and the contract collects from the buyer on the due date and pays the investors.

Built at ETHGlobal Mumbai 2026 for the Whitechain "Tokenize · Real World Finance" track.

**Status:** in progress. See [docs/PLAN.md](docs/PLAN.md) for the design and schedule.

Setup, architecture, deployed contracts and limitations will be added here as each part lands.
